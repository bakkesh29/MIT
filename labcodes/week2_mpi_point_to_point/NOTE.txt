--------------------------------------------------------------------------------
PROGRAM 1: parallel_calculator.c
--------------------------------------------------------------------------------
Process Count:
  Requires exactly 5 processes (-np 5)
  (Rank 0 = Coordinator, Rank 1 = Add, Rank 2 = Sub, Rank 3 = Mul, Rank 4 = Div)

Create/Open:
  nano parallel_calculator.c

Compile:
  mpicc parallel_calculator.c -o parallel_calculator

Run:
  mpirun -np 5 ./parallel_calculator

Sample Input:
  Enter operand 1 (a): 20
  Enter operand 2 (b): 4

Expected Output:
  --- Results Received by Coordinator (Rank 0) ---
  Rank 1 (Addition)       : 20.00 + 4.00 = 24.00
  Rank 2 (Subtraction)    : 20.00 - 4.00 = 16.00
  Rank 3 (Multiplication) : 20.00 * 4.00 = 80.00
  Rank 4 (Division)       : 20.00 / 4.00 = 5.00

--------------------------------------------------------------------------------
PROGRAM 2: synchronous_send_toggle.c
--------------------------------------------------------------------------------
Process Count:
  Requires exactly 2 processes (-np 2)

Create/Open:
  nano synchronous_send_toggle.c

Compile:
  mpicc synchronous_send_toggle.c -o synchronous_send_toggle

Run:
  mpirun -np 2 ./synchronous_send_toggle

Sample Input:
  Enter a word/string: HelloCUDA

Expected Output:
  [Rank 0] Sending original word: "HelloCUDA" to Rank 1 via MPI_Ssend...
  [Rank 1] Received: "HelloCUDA". Toggling letter cases...
  [Rank 1] Sending toggled word back to Rank 0 via MPI_Ssend...
  [Rank 0] Received toggled word from Rank 1: "hELLOcuda"
