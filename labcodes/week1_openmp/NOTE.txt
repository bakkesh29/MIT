UBUNTU WORKSPACE COMMANDS
--------------------------------------------------------------------------------
mkdir -p HPCS_Labs/week1_openmp
cd HPCS_Labs/week1_openmp

--------------------------------------------------------------------------------
PROGRAM 1: shared_private.c
--------------------------------------------------------------------------------
Create/Open:
  nano shared_private.c

Compile:
  gcc -fopenmp shared_private.c -o shared_private

Run:
  ./shared_private

Sample Input:
  (No input required; prints thread scoping demonstration)

Expected Output:
  Before Parallel Region:
    shared_var  = 100
    private_var = 0

  [Thread 0 of 4] private_var = 10, shared_var = 100
  [Thread 1 of 4] private_var = 20, shared_var = 105
  [Thread 2 of 4] private_var = 30, shared_var = 110
  [Thread 3 of 4] private_var = 40, shared_var = 115

  After Parallel Region:
    shared_var  = 120 (modified by all threads)
    private_var = 0 (original master copy unchanged)

--------------------------------------------------------------------------------
PROGRAM 2: array_add_core_threads.c
--------------------------------------------------------------------------------
Create/Open:
  nano array_add_core_threads.c

Compile:
  gcc -fopenmp array_add_core_threads.c -o array_add_core_threads

Run:
  ./array_add_core_threads

Sample Input:
  Enter number of elements (N): 4
  Enter 4 elements for array A:
  1 2 3 4
  Enter 4 elements for array B:
  10 20 30 40

Expected Output:
  Detected available CPU cores: 4
  Computing array addition in parallel using 4 threads...
  [Thread 0] C[0] = 1 + 10 = 11
  [Thread 1] C[1] = 2 + 20 = 22
  [Thread 2] C[2] = 3 + 30 = 33
  [Thread 3] C[3] = 4 + 40 = 44

  --- Resulting Array C (A + B) ---
  11 22 33 44
