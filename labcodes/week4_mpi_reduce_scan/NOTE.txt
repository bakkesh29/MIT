--------------------------------------------------------------------------------
PROGRAM 1: factorial_sum_scan.c
--------------------------------------------------------------------------------
Process Count:
  Run with desired number of terms N (keep N <= 12 to avoid 64-bit overflow).
  Example below uses: -np 4 (computes 1! + 2! + 3! + 4!).

Create/Open:
  nano factorial_sum_scan.c

Compile:
  mpicc factorial_sum_scan.c -o factorial_sum_scan

Run:
  mpirun -np 4 ./factorial_sum_scan

Sample Input:
  (No interactive input required; uses process ranks)

Expected Output:
  Total active processes (N) = 4
  Computing series: 1! + 2! + ... + 4!

  [Process 0] Number: 1 -> Factorial: 1 -> Cumulative Prefix Sum: 1 (Time: ...)
  [Process 1] Number: 2 -> Factorial: 2 -> Cumulative Prefix Sum: 3 (Time: ...)
  [Process 2] Number: 3 -> Factorial: 6 -> Cumulative Prefix Sum: 9 (Time: ...)
  [Process 3] Number: 4 -> Factorial: 24 -> Cumulative Prefix Sum: 33 (Time: ...)

  ============================================================
  Final Series Sum (1! + 2! + ... + 4!) = 33
  Total Elapsed Execution Time          = ... seconds
  ============================================================

--------------------------------------------------------------------------------
PROGRAM 2: matrix_search_reduce.c
--------------------------------------------------------------------------------
Process Count:
  Requires exactly 3 processes (-np 3), one process per row of the 3x3 matrix.

Create/Open:
  nano matrix_search_reduce.c

Compile:
  mpicc matrix_search_reduce.c -o matrix_search_reduce

Run:
  mpirun -np 3 ./matrix_search_reduce

Sample Input:
  Enter 9 elements for the 3x3 matrix row-wise:
    Row 0 (3 elements): 5 8 2
    Row 1 (3 elements): 2 9 2
    Row 2 (3 elements): 7 2 4
  Enter target value to search: 2

Expected Output:
  [Process 0] Row elements: [5, 8, 2] -> Found target 2: 1 time(s)
  [Process 1] Row elements: [2, 9, 2] -> Found target 2: 2 time(s)
  [Process 2] Row elements: [7, 2, 4] -> Found target 2: 1 time(s)

  --- Search Summary ---
  Target Value        : 2
  Total Occurrences   : 4
  Status              : Target was found in the matrix!

--------------------------------------------------------------------------------
PROGRAM 3: matrix_prefix_scan.c
--------------------------------------------------------------------------------
Process Count:
  Requires exactly 4 processes (-np 4), one process per row of the 4x4 matrix.

Create/Open:
  nano matrix_prefix_scan.c

Compile:
  mpicc matrix_prefix_scan.c -o matrix_prefix_scan

Run:
  mpirun -np 4 ./matrix_prefix_scan

Sample Input:
  Enter 16 elements for the 4x4 matrix row-wise:
    Row 0 (4 integers): 1 2 3 4
    Row 1 (4 integers): 1 2 3 1
    Row 2 (4 integers): 1 1 1 1
    Row 3 (4 integers): 2 1 2 1

Expected Output:
  Original Input Matrix:
     1    2    3    4 
     1    2    3    1 
     1    1    1    1 
     2    1    2    1 

  Resulting Column-Wise Prefix Sum Matrix (MPI_Scan):
     1    2    3    4 
     2    4    6    5 
     3    5    7    6 
     5    6    9    7 

--------------------------------------------------------------------------------
PROGRAM 4: repeated_character_pattern.c
--------------------------------------------------------------------------------
Process Count:
  The process count -np MUST EQUAL the exact length of the word entered.
  For word "PCAP" (length 4), use: -np 4.

Create/Open:
  nano repeated_character_pattern.c

Compile:
  mpicc repeated_character_pattern.c -o repeated_character_pattern

Run:
  mpirun -np 4 ./repeated_character_pattern

Sample Input:
  Enter a word of exactly 4 characters: PCAP

Expected Output:
  --- Generated Pattern Result ---
  Original Word : PCAP (Length 4)
  Result Pattern: PCCAAAPPPP (Length 10)
